# Todoer Mobile Apps — Capacitor Design Document

**Date:** 2026-02-27
**Status:** Approved
**Approach:** Capacitor (free) + GitHub Actions for iOS cloud builds (free)

## Context

Todoer is a Todoist-clone PWA built with Next.js 16, Supabase, TanStack Query, Tailwind CSS, Zustand, and @dnd-kit. It's deployed on Vercel at todoer-ruby.vercel.app. The goal is to ship native iOS and Android apps to the App Store and Play Store with minimal code changes.

**Constraints:**
- Development machine is Windows only (no Mac)
- No paid build services — must be free
- Both Apple Developer and Google Play Developer accounts are active

## Architecture

```
┌─────────────────────────────────────────────┐
│           Next.js App (static export)        │
│  ┌───────────────────────────────────────┐  │
│  │  React + TanStack Query + Supabase    │  │
│  │  (existing code, minimal changes)     │  │
│  └───────────────────────────────────────┘  │
├─────────────────────────────────────────────┤
│        Capacitor Bridge Layer               │
│  Push Notifications │ Status Bar │ Splash   │
│  Haptics │ App State │ Keyboard │ Storage   │
├──────────────────┬──────────────────────────┤
│   iOS (Swift)    │   Android (Kotlin)       │
│   WKWebView      │   Android WebView        │
│   Xcode project  │   Android Studio project │
└──────────────────┴──────────────────────────┘
```

The web app is statically exported (`output: 'export'`), bundled into the native app binary, and loaded locally from the device filesystem. No remote server needed for the UI layer.

## Key Changes

### 1. Next.js Static Export

- Add `output: 'export'` to `next.config.ts`
- Remove `middleware.ts` (server-only, incompatible with static export)
- Create client-side `<AuthGuard>` component to replace middleware auth redirects
- All existing React components, hooks, stores, and styles remain unchanged

### 2. Capacitor Plugins

| Feature | Web (current) | Native (Capacitor) | Plugin |
|---------|--------------|---------------------|--------|
| Push Notifications | Web Push API | APNs / FCM | `@capacitor/push-notifications` |
| Status Bar | N/A | Native styling | `@capacitor/status-bar` |
| Splash Screen | N/A | Native splash | `@capacitor/splash-screen` |
| Haptic Feedback | N/A | Vibration | `@capacitor/haptics` |
| App State | visibilitychange | Background/foreground | `@capacitor/app` |
| Keyboard | N/A | Native keyboard | `@capacitor/keyboard` |
| Local Storage | localStorage | Works in WebView | Built-in |
| Audio | Web Audio API | Works in WebView | Built-in |

### 3. Platform Detection

```ts
import { Capacitor } from '@capacitor/core'
const isNative = Capacitor.isNativePlatform()
```

Branch logic: native push on mobile, web-push on browser.

### 4. OAuth Deep Linking

- Custom URL scheme: `com.todoer.app://`
- Supabase OAuth redirects back into the app via deep link
- Uses `@capacitor/browser` for in-app OAuth browser flow

### 5. App Icons & Splash Screens

- Source: existing SVG icon (purple rounded rect with checkmark)
- Generate all required PNG sizes:
  - iOS: 1024x1024 (App Store) + home screen sizes
  - Android: 512x512 (Play Store) + adaptive icon layers
- Splash screens generated via Capacitor splash screen tooling

### 6. Build & Distribution (GitHub Actions)

```
Developer (Windows) → git push → GitHub Actions
                                   ├── macOS Runner: next build → cap sync → xcodebuild → App Store Connect
                                   └── Ubuntu Runner: next build → cap sync → gradle → Play Store
```

**Signing:**
- iOS: Certificate + provisioning profile in GitHub Secrets
- Android: Keystore in GitHub Secrets

## Files Created/Modified

### New files:
- `capacitor.config.ts` — Capacitor configuration
- `ios/` — Xcode project (generated by `cap add ios`)
- `android/` — Android Studio project (generated by `cap add android`)
- `src/components/AuthGuard.tsx` — Client-side auth redirect
- `src/lib/native/notifications.ts` — Platform-aware push notification setup
- `src/lib/native/platform.ts` — Platform detection utilities
- `.github/workflows/build-ios.yml` — iOS CI/CD
- `.github/workflows/build-android.yml` — Android CI/CD
- `resources/icon.png` — 1024x1024 source icon
- `resources/splash.png` — 2732x2732 source splash

### Modified files:
- `next.config.ts` — Add `output: 'export'`
- `src/app/layout.tsx` — Conditionally skip SW registration on native
- `src/components/ServiceWorkerRegistration.tsx` — Skip on native platform
- `src/components/NagReminder.tsx` — Use native notifications when available
- `package.json` — Add Capacitor dependencies and scripts

### Removed files:
- `src/middleware.ts` — Replaced by client-side AuthGuard

## Out of Scope

- No UI redesign
- No feature additions
- No React Native rewrite
- No paid build services
